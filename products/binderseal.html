What it does

  • Walks a folder of reports, PDFs, CSVs, logs, checklists, or any files
  • Computes deterministic SHA-256 of each file’s exact bytes
  • Builds a sorted manifest (path, size, mtime)
  • Seals into a QuantumGuard CONTRACT-v1 evidence pack (Ed25519)
  • Optional HTML report for auditors
  • Client verifies offline with free qg verify → PASS / FAIL / INDETERMINATE
